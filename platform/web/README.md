# Nish Alpha Hive

Scaffolded by [AI Alpha Hive](https://github.com/nishgaba-ai/ai-alpha-hive)
from the `marketing` template.

Intent: Get founders and devs to launch their product to production in minutes

```bash
npm run dev      # local development
hive check       # policy gates (secrets, deps, types, lint, build, links, seo)
hive ship        # gates → deploy preview to Vercel
hive ship --env prod
```

Declared intent lives in `hive.yaml` — keep it current; the drift gate
(phase 2) will hold content to it.
